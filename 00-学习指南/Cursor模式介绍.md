# Cursor 模式介绍

## 三种主要模式

### 1. Ask 模式（问答模式）

**特点：**
- 只读模式，AI 不会修改任何文件
- 适合：提问、理解代码、获取建议、学习概念
- AI 可以：阅读文件、搜索代码、解释逻辑、给出方案
- AI 不会：创建/修改文件、运行命令、执行脚本

**适用场景：**
- "这段代码是什么意思？"
- "Vue 的响应式原理是什么？"
- "帮我看看这个报错可能是什么原因？"
- 需要纯咨询、不想被改代码时

---

### 2. Agent 模式（代理模式）⭐ 当前模式

**特点：**
- 完整权限，AI 可以读写文件、执行命令
- 适合：实现功能、重构代码、创建项目、批量修改
- AI 可以：创建/编辑文件、运行终端命令、安装依赖、执行测试
- 会主动使用工具完成任务

**适用场景：**
- "帮我创建这个学习计划的文件夹结构"
- "实现一个深拷贝函数"
- "把这个 Vue2 项目改成 Vue3"
- 需要动手实现、搭建项目时

---

### 3. Chat 模式（对话模式）

**特点：**
- 类似 Ask，但更偏向对话式交流
- 可以引用文件、讨论方案
- 通常也是只读，具体取决于你的设置

---

## 模式选择建议

| 需求 | 推荐模式 |
|------|----------|
| 学习概念、问原理 | Ask |
| 写代码、建项目、改文件 | Agent |
| 快速对话、讨论思路 | Chat |

---

## 小技巧

- **切换模式**：在输入框上方或侧边可以切换 Ask / Agent
- **明确意图**：告诉 AI 你希望"只解释"还是"直接帮我写"
- **分步进行**：复杂任务可以先用 Ask 讨论方案，再用 Agent 实现
