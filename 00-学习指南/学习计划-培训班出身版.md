## 二、培训班出身的常见短板（针对性补强）

### 1. JavaScript 基础薄弱

- **表现**：能写业务，但原理说不清；闭包、原型链一知半解；遇到复杂异步就懵
- **原因**：培训重框架、轻基础，缺少系统学习
- **对策**：从零梳理 JS 核心，每个概念都要能讲、能写、能画图

### 2. 工程化薄弱

- **表现**：只会 `npm run dev`，不懂打包流程；环境变量、代理配置靠复制；部署流程不清晰
- **原因**：培训项目多为脚手架一键生成，缺少从零搭建经验
- **对策**：手把手配置一次 Webpack/Vite，理解每个配置项的作用

### 3. 网络知识薄弱

- **表现**：HTTP 状态码记不住、缓存策略说不清、跨域只会配代理；输入 URL 到页面展示讲不全
- **原因**：培训多用现成接口，很少讲网络原理
- **对策**：单独成块学习，按「请求发出 → 响应返回 → 缓存 → 跨域」这条线串起来

### 4. 计算机基础薄弱

- **表现**：数据结构、算法几乎没接触
- **原因**：培训周期短，侧重"能干活"
- **对策**：按面试高频考点补，不求深，求"能说清楚"

## 三、调整后的学习路线（约 11–13 周）

> 基础 + 网络 + 工程化 三个短板单独成块，节奏放慢一点

### 第一阶段：JavaScript 基础夯实（约 3 周）⚠️ 重点

| 单元 | 内容 | 学习重点 | 自测标准 |
|------|------|----------|----------|
| **Unit 1** | 作用域、闭包、this、执行上下文 | 画图理解、手写示例 | 能口述并画图 |
| **Unit 2** | 原型链、继承、ES6 Class | 手写多种继承方式 | 能手写寄生组合继承 |
| **Unit 3** | 事件循环、宏任务/微任务 | 做 10+ 道输出题 | 能解释任意题目的输出 |
| **Unit 4** | Promise、async/await | 手写 Promise、理解链式调用 | 能手写简易 Promise |
| **Unit 5** | 数组/对象 API、类型判断、深拷贝 | 手写实现 | 能手写深拷贝、防抖节流 |

**建议**：每个单元至少 2 天，不要赶进度，确保真正理解。

## 四、培训班出身面试常见追问

提前准备这些问题的回答：

1. **"你是科班还是培训班？"**
   - 诚实说培训班，强调：有 2.5 年实战、能独立负责项目、持续自学补基础

2. **"为什么 Vue2 不能直接监听数组变化？"**
   - 考察响应式原理，必须能答

3. **"从输入 URL 到页面展示发生了什么？"**
   - 考察网络，必须能答（DNS → TCP → HTTP → 渲染）

4. **"Webpack 打包流程是怎样的？"**
   - 考察工程化，必须能答

5. **"强缓存和协商缓存的区别？"**
   - 考察缓存，必须能讲清

6. **"你做过哪些性能优化？"**
   - 准备 2–3 个具体案例（懒加载、图片优化、接口合并等）

7. **"手写一个深拷贝"**
   - 必须能手写，包括处理循环引用
