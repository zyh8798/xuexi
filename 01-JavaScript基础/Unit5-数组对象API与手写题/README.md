# Unit 5：数组/对象 API、类型判断、深拷贝

## 学习顺序

1. **阅读** `notes.md`（约 40 分钟）
2. **运行** `examples/` 下的示例，边看边练（约 40 分钟）
3. **完成** `quiz.md` 自测题（约 30 分钟）
4. **过关测验** `exam-unit5.md`（约 30 分钟）

## 文件说明

| 文件 | 说明 |
|------|------|
| notes.md | 数组/对象常用 API、类型判断、深拷贝、防抖节流 |
| examples/ | 手写示例代码 |
| quiz.md | 自测题 + 答案（折叠） |
| exam-unit5.md | 单元测验（过关用） |

## 过关标准

- 能手写深拷贝（考虑循环引用、Date、RegExp 等）
- 能手写防抖、节流
- 能说清 typeof / instanceof / Object.prototype.toString 区别

过关后完成 **01-JavaScript 基础**，可进入 **02-Vue 深入** 或按计划继续。
