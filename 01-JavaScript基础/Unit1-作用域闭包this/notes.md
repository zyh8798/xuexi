# Unit 1：作用域、闭包、this、执行上下文

## 一、作用域（Scope）

### 1.1 什么是作用域？

作用域决定了**变量和函数的可访问范围**。JS 是词法作用域（静态作用域），作用域在**写代码时**就确定了，不是运行时。

### 1.2 三种作用域

| 类型 | 声明方式 | 特点 |
|------|----------|------|
| **全局作用域** | 最外层、未用 var/let/const | 随处可访问，易污染 |
| **函数作用域** | function 内部 | 函数内可访问，函数外不可 |
| **块级作用域** | `{}` 内用 let/const | ES6 新增，if/for 等块内有效 |

### 1.3 var / let / const 区别

| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 重复声明 | ✅ 允许 | ❌ 不允许 | ❌ 不允许 |
| 变量提升 | ✅ 有（值为 undefined） | ⚠️ 有暂时性死区 | ⚠️ 有暂时性死区 |
| 必须初始化 | ❌ | ❌ | ✅ 必须 |

```javascript
// var 函数作用域
function fn() {
  if (true) {
    var a = 1;
  }
  console.log(a); // 1，var 穿透了 if 块
}

// let 块级作用域
function fn2() {
  if (true) {
    let b = 2;
  }
  console.log(b); // ReferenceError，b 只在 if 块内
}
```

### 1.4 作用域链

查找变量时，从**当前作用域**往**外层作用域**逐级查找，直到全局。形成一条链。

```
当前函数 → 外层函数 → ... → 全局
```

## 二、闭包（Closure）

### 2.1 定义

**闭包 = 函数 + 它能访问的外层变量**。  
当一个函数可以访问并「记住」其词法作用域中的变量，即使该函数在其词法作用域之外执行，就形成了闭包。

### 2.2 形成条件

1. 有函数嵌套
2. 内层函数引用外层函数的变量
3. 内层函数被返回或在外部被使用（导致外层函数执行完，变量仍被引用）

### 2.3 常见用途

| 用途 | 示例 |
|------|------|
| 数据私有化 | 模块模式、封装变量 |
| 柯里化 / 偏函数 | 固定部分参数 |
| 防抖 / 节流 | 保存 timer |
| 循环中保存 i | for 循环 + 异步回调 |

### 2.4 闭包与内存

- 闭包会**保持对外层变量的引用**，外层函数的变量不会被 GC 回收
- 若闭包引用的是大对象且长期存在，可能导致**内存泄漏**
- 解决：用完后将引用置为 null，或避免不必要的闭包

## 三、this

### 3.1 this 是什么？

`this` 是函数**运行时**的上下文对象，指向谁取决于**调用方式**，不是定义时。

### 3.2 四种绑定规则（优先级从低到高）

| 规则 | 情况 | this 指向 |
|------|------|----------|
| **默认绑定** | 独立函数调用 | 严格模式 undefined，非严格模式 window |
| **隐式绑定** | obj.fn() | obj |
| **显式绑定** | call/apply/bind | 传入的第一个参数 |
| **new 绑定** | new Fn() | 新创建的对象 |

### 3.3 箭头函数与 this

- 箭头函数**没有自己的 this**，继承外层（词法作用域）的 this
- 不能用作构造函数，不能用 call/apply/bind 改变 this
- 常用于回调中保持外层 this（如 Vue 中）

```javascript
const obj = {
  name: 'obj',
  fn: function() {
    console.log(this.name);        // obj
    setTimeout(() => {
      console.log(this.name);     // obj，箭头函数继承 fn 的 this
    }, 100);
  }
};
```

## 四、执行上下文（Execution Context）

### 4.1 概念

执行上下文是 JS 执行代码时的**环境**，包含：变量对象、作用域链、this。

### 4.2 类型

- **全局执行上下文**：代码开始执行时创建
- **函数执行上下文**：每次调用函数时创建
- **eval 执行上下文**：eval 内部（少用）

### 4.3 执行上下文栈（调用栈）

- 栈底是全局上下文，每次调用函数就压入一个函数上下文
- 函数执行完就弹出，控制权交回上一个上下文

### 4.4 变量提升（Hoisting）

- **var**：声明提升到当前作用域顶部，值为 `undefined`
- **function 声明**：整体提升，可先调用后定义
- **let/const**：有「暂时性死区」（TDZ），声明前访问会报错

```javascript
console.log(a);     // undefined（var 提升）
var a = 1;

console.log(b);     // ReferenceError（TDZ）
let b = 2;
```

### 4.5 暂时性死区（TDZ）

从块开始到 `let/const` 声明之间的区域，访问变量会报错。
