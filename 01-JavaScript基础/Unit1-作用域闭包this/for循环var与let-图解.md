# for 循环里 var 与 let：作用域链图解

## 一、用 var 时：为什么是 3 3 3

```javascript
for (var i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i);
  }, 1000);
}
```

### 关键：var 是「函数作用域」，整个 for 只在一个作用域里

可以理解为：**只有一个 i**，而且这个 i 不在 for 的「块」里，而在**包裹 for 的那一层**（全局或外层函数）。

```
┌─────────────────────────────────────────────────────────┐
│  外层作用域（全局或所在函数）                              │
│                                                          │
│    i  ← 只有这一个变量！var 把 i 声明在这一层              │
│                                                          │
│    for (var i = 0; i < 3; i++) {   ← 循环体没有新作用域   │
│  ┌──────────────────────────────────────────────────┐  │
│  │  第 1 次迭代：i = 0，注册 setTimeout(回调1)          │  │
│  │  第 2 次迭代：i = 1，注册 setTimeout(回调2)          │  │
│  │  第 3 次迭代：i = 2，注册 setTimeout(回调3)          │  │
│  │  然后 i++ → i = 3，条件 i < 3 不成立，退出循环       │  │
│  └──────────────────────────────────────────────────┘  │
│                                                          │
│    此时 i 已经等于 3                                       │
└─────────────────────────────────────────────────────────┘

  约 1 秒后，三个回调依次执行：
  回调1 里访问 i → 去「外层」找 → 找到同一个 i，值是 3 → 打印 3
  回调2 里访问 i → 去「外层」找 → 找到同一个 i，值是 3 → 打印 3
  回调3 里访问 i → 去「外层」找 → 找到同一个 i，值是 3 → 打印 3
```

### 时间线（var）

| 时刻 | 发生的事 | 此时 i 的值 |
|------|----------|-------------|
| 循环第 1 次 | i=0，注册回调1（还没执行） | 0 |
| 循环第 2 次 | i=1，注册回调2 | 1 |
| 循环第 3 次 | i=2，注册回调3 | 2 |
| 循环结束 | i++ 变成 3，退出 for | **3** |
| 约 1 秒后 | 回调1 执行，读 i | **3**（因为只有一个 i，已经变成 3） |
| 约 1 秒后 | 回调2 执行，读 i | **3** |
| 约 1 秒后 | 回调3 执行，读 i | **3** |

所以：**三个回调闭包的是「同一个 i」**，等它们执行时，循环早结束了，这个 i 已经是 3，于是打出 3 3 3。

## 二、用 let 时：为什么是 0 1 2

```javascript
for (let i = 0; i < 3; i++) {
  setTimeout(function() {
    console.log(i);
  }, 1000);
}
```

### 关键：let 在 for 里会「每次迭代一个块级作用域」，每次有一个新的 i

规范里，**for (let i = ...)** 在每次迭代都会创建一个**新的块级作用域**，并且有一个**新的 i**（可以理解为「这一轮的 i」）。

```
迭代 0：
┌─────────────────────────────┐
│  块级作用域（第 1 次迭代）    │
│    i = 0  ← 只属于这次迭代   │
│    setTimeout(回调1)        │  回调1 闭包的是「这个 i」
└─────────────────────────────┘

迭代 1：
┌─────────────────────────────┐
│  块级作用域（第 2 次迭代）    │
│    i = 1  ← 新的 i          │
│    setTimeout(回调2)        │  回调2 闭包的是「这个 i」
└─────────────────────────────┘

迭代 2：
┌─────────────────────────────┐
│  块级作用域（第 3 次迭代）    │
│    i = 2  ← 新的 i          │
│    setTimeout(回调3)        │  回调3 闭包的是「这个 i」
└─────────────────────────────┘
```

### 时间线（let）

| 时刻 | 发生的事 | 各回调闭包到的 i |
|------|----------|------------------|
| 第 1 次迭代 | 创建块1，i₁=0，注册回调1 | 回调1 → i₁ |
| 第 2 次迭代 | 创建块2，i₂=1，注册回调2 | 回调2 → i₂ |
| 第 3 次迭代 | 创建块3，i₃=2，注册回调3 | 回调3 → i₃ |
| 约 1 秒后 | 回调1 执行，读自己闭包里的 i₁ | 0 |
| 约 1 秒后 | 回调2 执行，读自己闭包里的 i₂ | 1 |
| 约 1 秒后 | 回调3 执行，读自己闭包里的 i₃ | 2 |

所以：**每个回调闭包的是「当次迭代的那一个 i」**，互不干扰，打出 0 1 2。

---

## 三、对比小结

|        | var                         | let（在 for 里）                    |
|--------|-----------------------------|--------------------------------------|
| i 有几个 | **1 个**，在外层作用域       | **每轮迭代 1 个**，在当次的块里      |
| 回调闭包的是 | 同一个 i                    | 各自当次的 i                         |
| 执行时读到的 i | 循环结束后的值（3）          | 当时那次迭代的值（0、1、2）          |
| 结果   | 3 3 3                       | 0 1 2                               |

一句话：**var 只有一个 i，大家共用一个；let 每轮一个 i，各用各的。**
