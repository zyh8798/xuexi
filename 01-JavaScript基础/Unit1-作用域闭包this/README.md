# Unit 1：作用域、闭包、this、执行上下文

## 学习顺序

1. **阅读** `notes.md`（约 30 分钟）
2. **运行** `examples/` 下的 4 个示例，边看边理解（约 20 分钟）
3. **完成** `quiz.md` 自测题（约 30 分钟）

## 文件说明

| 文件 | 说明 |
|------|------|
| notes.md | 知识点笔记，面试口述要点 |
| examples/01-作用域.js | var/let/const、作用域链 |
| examples/02-闭包.js | 闭包基础、数据私有、循环坑 |
| examples/03-this.js | 四种绑定、箭头函数 |
| examples/04-执行上下文.js | 变量提升、TDZ、调用栈 |
| examples/05-函数构造函数原型与执行上下文.js | 函数/构造函数/原型、eval、执行栈 |
| quiz.md | 自测题 + 答案（折叠） |
| 05-补充笔记-函数原型eval执行栈.md | 函数/构造函数/原型、eval、执行栈 详解 |

## 运行示例

```bash
cd examples
node 01-作用域.js
node 02-闭包.js
node 03-this.js
node 04-执行上下文.js
node 05-函数构造函数原型与执行上下文.js
```

## 过关标准

- 选择题 4/4 正确
- 输出题能独立推理
- 简答题能脱稿口述
- 能画出作用域链

过关后进入 **Unit 2：原型链、继承**。
