# Unit 2：原型链、继承、ES6 Class

## 学习顺序

1. **阅读** `notes.md`（约 40 分钟）
2. **运行** `examples/` 下的 3 个示例，边看边理解（约 30 分钟）
3. **完成** `quiz.md` 自测题（约 30 分钟）
4. **过关测验** `exam-unit2.md`（约 30 分钟）

## 文件说明

| 文件 | 说明 |
|------|------|
| notes.md | 知识点笔记，面试口述要点 |
| examples/01-原型链.js | prototype、__proto__、查找机制 |
| examples/02-继承.js | 多种继承方式、寄生组合继承 |
| examples/03-Class.js | ES6 Class 与继承 |
| quiz.md | 自测题 + 答案（折叠） |
| exam-unit2.md | 单元测验（过关用） |

## 运行示例

```bash
cd examples
node 01-原型链.js
node 02-继承.js
node 03-Class.js
```

## 过关标准

- 选择题 4/4 正确
- 能手写**寄生组合继承**
- 能画出原型链关系图
- 能说清 Class 与 ES5 继承的对应关系

过关后进入 **Unit 3：事件循环、宏任务/微任务**。
