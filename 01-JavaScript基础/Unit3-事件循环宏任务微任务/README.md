# Unit 3：事件循环、宏任务、微任务

## 学习顺序

1. **阅读** `notes.md`（约 40 分钟）
2. **运行** `examples/` 下的示例，边看边理解（约 30 分钟）
3. **完成** `quiz.md` 自测题（约 30 分钟）
4. **过关测验** `exam-unit3.md`（约 30 分钟）

## 文件说明

| 文件 | 说明 |
|------|------|
| notes.md | 知识点笔记，事件循环、宏任务、微任务 |
| examples/ | 输出题示例代码 |
| quiz.md | 自测题 + 答案（折叠） |
| exam-unit3.md | 单元测验（过关用） |

## 过关标准

- 能解释任意事件循环输出题的输出顺序
- 能说明宏任务、微任务、调用栈的关系
- 能画图讲清一轮事件循环的执行顺序

过关后进入 **Unit 4：Promise、async/await**。
