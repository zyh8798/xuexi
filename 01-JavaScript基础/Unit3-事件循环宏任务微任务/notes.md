# Unit 3 笔记：事件循环、宏任务、微任务

## 一、事件循环（Event Loop）核心

### 1. 为什么需要事件循环？

JavaScript 是**单线程**的，同一时刻只能执行一段代码。但浏览器要处理：
- 用户点击、输入
- 定时器、网络请求
- 渲染等

所以需要**事件循环**：主线程执行完同步代码后，不断从任务队列里取任务执行。

### 2. 调用栈（Call Stack）

- 同步代码按顺序入栈、出栈执行
- 函数调用时入栈，返回时出栈

### 3. 任务队列

- **宏任务（Macro Task）**：setTimeout、setInterval、I/O、UI 渲染
- **微任务（Micro Task）**：Promise.then、queueMicrotask、MutationObserver

### 4. 一轮事件循环顺序

1. 执行完**当前宏任务**（同步代码）
2. 执行**所有微任务**（清空微任务队列）
3. 可选：渲染（浏览器）
4. 取下一个**宏任务**，回到步骤 1

---

## 二、输出题常见规律

- 先同步，再微任务，再宏任务
- 同类型任务按入队顺序执行
- 微任务在**当前宏任务结束后、下一个宏任务之前**全部执行完

## 三、面试口述要点

1. JS 单线程，事件循环解决异步
2. 宏任务：setTimeout、setInterval、I/O
3. 微任务：Promise.then、queueMicrotask
4. 顺序：同步 → 微任务 → 宏任务 → 微任务 → …
