# Unit 4：Promise、async/await

## 学习顺序

1. **阅读** `notes.md`（约 40 分钟）
2. **运行** `examples/` 下的示例，边看边理解（约 30 分钟）
3. **完成** `quiz.md` 自测题（约 30 分钟）
4. **过关测验** `exam-unit4.md`（约 30 分钟）

## 文件说明

| 文件 | 说明 |
|------|------|

| quiz.md | 自测题 + 答案（折叠） |

- 能说清 async/await 与 Promise 的对应关系
