# Vue2 响应式原理图解

## 一、整体架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         用户代码层                                │
│  ┌─────────────────┐    ┌─────────────────┐                     │
│  │  new Watcher()  │    │  data.name = 'x'│                     │
│  │  (订阅数据变化)  │    │  (修改数据)      │                     │
│  └────────┬────────┘    └────────┬────────┘                     │
└───────────┼──────────────────────┼───────────────────────────────┘
            │                      │
            ▼                      ▼
┌─────────────────────────────────────────────────────────────────┐
│                      响应式系统核心层                             │
│                                                                 │
│   ┌─────────────────────┐        ┌─────────────────────┐       │
│   │    Vue2Reactive     │        │       Watcher       │       │
│   │   (响应式处理器)     │        │      (订阅者)        │       │
│   │                     │        │                     │       │
│   │  ┌───────────────┐  │        │  ┌───────────────┐  │       │
│   │  │ defineReactive│  │        │  │   get()       │  │       │
│   │  │  (劫持get/set)│◄─┼────────┼──┤  读取数据      │  │       │
│   │  └───────┬───────┘  │        │  │  触发getter   │  │       │
│   │          │          │        │  └───────┬───────┘  │       │
│   │          ▼          │        │          │          │       │
│   │  ┌───────────────┐  │        │          ▼          │       │
│   │  │   getter()    │  │        │  ┌───────────────┐  │       │
│   │  │  收集依赖      │  │        │  │ Dep.target    │  │       │
│   │  │  dep.addSub() │◄─┼────────┼──┤   = this      │  │       │
│   │  └───────┬───────┘  │        │  └───────────────┘  │       │
│   │          │          │        │                     │       │
│   │          ▼          │        │  ┌───────────────┐  │       │
│   │  ┌───────────────┐  │        │  │   update()    │  │       │
│   │  │   setter()    │  │        │  │  数据变化回调  │  │       │
│   │  │  dep.notify() │──┼────────┼─►│  执行cb()     │  │       │
│   │  └───────────────┘  │        │  └───────────────┘  │       │
│   └─────────────────────┘        └─────────────────────┘       │
│                                                                 │
│   ┌─────────────────────────────────────────────────────┐      │
│   │                      Dep 类                          │      │
│   │  ┌─────────────────────────────────────────────┐   │      │
│   │  │  静态属性: Dep.target = null 或 Watcher实例  │   │      │
│   │  │  (全局临时标记，标记当前正在收集依赖的Watcher) │   │      │
│   │  └─────────────────────────────────────────────┘   │      │
│   │                                                     │      │
│   │  实例属性: dep.subs = [Watcher1, Watcher2, ...]     │      │
│   │  (每个响应式属性都有一个Dep实例，存储订阅者列表)       │      │
│   └─────────────────────────────────────────────────────┘      │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## 二、依赖收集流程（初始化阶段）

```
步骤1: 创建 Watcher
┌────────────────────────────────────────┐
│  new Watcher(data, 'name', callback)   │
│              │                         │
│              ▼                         │
│  ┌────────────────────────────────┐   │
│  │  constructor() {               │   │
│  │    this.value = this.get()     │   │
│  │  }                             │   │
│  └────────────────────────────────┘   │
└────────────────────────────────────────┘
                   │
                   ▼
步骤2: Watcher.get() 开始收集
┌────────────────────────────────────────┐
│  get() {                               │
│    ┌──────────────────────────────┐   │
│    │ Dep.target = this  ◄────────┐│   │
│    │ (标记自己为当前收集者)        ││   │
│    └──────────────────────────────┘│   │
│              │                      │   │
│              ▼                      │   │
│    const value = data.name ─────────┘   │
│    (触发 getter)                        │
└────────────────────────────────────────┘
                   │
                   ▼
步骤3: 触发 getter，收集依赖
┌────────────────────────────────────────┐
│  defineReactive 的 getter {            │
│              │                         │
│              ▼                         │
│    if (Dep.target) {  ◄── 检查是否有    │
│                         Watcher 在收集  │
│              │                         │
│              ▼                         │
│      dep.addSub(Dep.target)            │
│      (把 Watcher 加入该属性的订阅列表)   │
│    }                                   │
│  }                                     │
└────────────────────────────────────────┘
                   │
                   ▼
步骤4: 收集完成，清理标记
┌────────────────────────────────────────┐
│    return value                        │
│         │                              │
│         ▼                              │
│  Dep.target = null  ◄── 清理，防止      │
│         其他地方误收集                  │
└────────────────────────────────────────┘
```

## 三、数据更新流程（运行时）

```
步骤1: 修改数据
┌────────────────────────────────────────┐
│  data.name = 'Vue3'                    │
│         │                              │
│         ▼                              │
│  触发 defineReactive 的 setter         │
└────────────────────────────────────────┘
                   │
                   ▼
步骤2: 通知所有订阅者
┌────────────────────────────────────────┐
│  set(newVal) {                         │
│    val = newVal                        │
│         │                              │
│         ▼                              │
│    dep.notify()  ◄── 通知该属性的       │
│         所有 Watcher                    │
│  }                                     │
└────────────────────────────────────────┘
                   │
                   ▼
步骤3: Dep 遍历通知
┌────────────────────────────────────────┐
│  class Dep {                           │
│    notify() {                          │
│      this.subs.forEach(sub => {        │
│        sub.update()  ◄── 逐个调用      │
│      })      Watcher 的 update         │
│    }                                   │
│  }                                     │
│                                        │
│  subs = [Watcher1, Watcher2]           │
│           │        │                   │
│           ▼        ▼                   │
│        update()  update()              │
└────────────────────────────────────────┘
                   │
                   ▼
步骤4: Watcher 执行回调
┌────────────────────────────────────────┐
│  update() {                            │
│    const newValue = data.name          │
│    this.cb(newValue, oldValue)         │
│         │                              │
│         ▼                              │
│  console.log('name 变化了: Vue -> Vue3')│
│  (用户定义的回调被执行)                 │
└────────────────────────────────────────┘
```

## 四、Dep.target 作用机制

```
┌─────────────────────────────────────────────────────────────┐
│                     Dep 类（函数对象）                        │
│  ┌─────────────────────────────────────────────────────┐   │
│  │                                                     │   │
│  │   Dep.target ──────► null 或 Watcher 实例           │   │
│  │                                                     │   │
│  │   作用：全局临时标记，标记"当前正在收集依赖的Watcher"   │   │
│  │                                                     │   │
│  │   为什么挂到类上？                                   │   │
│  │   1. 任何地方都能访问到                              │   │
│  │   2. 只有一份，不会被实例化影响                       │   │
│  │   3. 不污染全局作用域                                │   │
│  │                                                     │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  实例化后：new Dep()                                         │
│  ┌─────────────────────────────────────────────────────┐   │
│  │   dep.subs = []  ◄── 存储订阅该属性的所有Watcher      │   │
│  │                                                     │   │
│  │   每个响应式属性都有一个独立的Dep实例                  │   │
│  │   data.name ──► dep1 (subs: [w1, w2])               │   │
│  │   data.age  ──► dep2 (subs: [w1])                   │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## 五、完整执行时序图

```
时间轴 ─────────────────────────────────────────────────────────►

用户代码
   │
   │    new Vue2Reactive(data)
   ├────────────────────────────► 遍历属性，defineReactive
   │                              每个属性创建对应的 dep
   │
   │    new Watcher(data, 'name', cb)
   ├────────────────────────────► Watcher.get()
   │                              Dep.target = thisWatcher
   │                              读取 data.name
   │                                   │
   │                                   ▼
   │                              触发 getter
   │                              dep.addSub(Dep.target)
   │                              Dep.target = null
   │                                   │
   │◄─────────────────────────────────┘
   │    初始化完成，Watcher 已订阅 name
   │
   │    data.name = 'Vue3'
   ├────────────────────────────► 触发 setter
   │                              dep.notify()
   │                              遍历 subs 调用 update()
   │                                   │
   │                                   ▼
   │                              Watcher.update()
   │                              执行 cb('Vue3', 'Vue')
   │                                   │
   │◄─────────────────────────────────┘
   │    控制台输出: name 变化了: Vue -> Vue3
   │
```

## 六、关键概念总结

| 概念 | 作用 | 类比 |
|------|------|------|
| `Vue2Reactive` | 把数据变成响应式 | 改装车，加装传感器 |
| `defineReactive` | 劫持属性的 get/set | 给每个车门装感应器 |
| `Dep` | 管理订阅者列表 | 物业的业主名单 |
| `dep.subs` | 存储 Watcher 数组 | 名单上的业主们 |
| `Dep.target` | 当前正在收集的 Watcher | 正在登记的业主 |
| `Watcher` | 监听数据变化并回调 | 业主，关心房价变化 |
| `watcher.get()` | 读取数据并收集依赖 | 业主去售楼处登记 |
| `watcher.update()` | 数据变化时执行回调 | 房价变了通知业主 |
