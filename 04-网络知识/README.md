## 学习主线

```
输入 URL → DNS 解析 → TCP 连接 → HTTP 请求 → 服务器响应 
    → 浏览器解析 → 渲染 → 缓存策略
                    ↓
              跨域、安全（CORS、XSS、CSRF）
```

## 面试必背

1. **从输入 URL 到页面展示** - 完整流程能口述
2. **HTTP 状态码** - 200/301/302/304/400/401/403/404/500 能解释
3. **强缓存 vs 协商缓存** - 能画图讲清
4. **跨域解决方案** - CORS、代理、JSONP 能说清
